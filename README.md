# Sales-Machine

The **brain** of GT Everyday's sales machine: doctrine, graded knowledge, recipes,
evidence, and agent declarations. **No runtime code.**

- Start here: `CLAUDE.md` (the truth constitution) → `CURRENT_STATE.md` (status +
  open unknowns) → `doctrine/decisions.md`.
- Core principle: slow truth (Tom-approved doctrine) is separated from fast truth
  (live data — computed via `recipes/`, snapshotted dated in `evidence/`, never stored
  as undated "facts").
- Governance gate: module declaration in `gt-factory-os-production-brain`
  (`docs/decisions/modules/sales-declaration.md`, PR #46).

Owner: Tom. Built knowledge-first, 2026-07.
