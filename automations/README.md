# Automations — deliberately empty

Nothing lives here until:
1. The knowledge base an automation depends on is verified (Phases 2–3 closed).
2. Its agent declaration exists (Phase 4).
3. Tom approved the automation explicitly.
4. If it touches customers: `SALES_CUSTOMER_OUTREACH_WRITE_ENABLED` flipped under the
   full ceremony (Tom written approval + dry-run + ≥24h soak) — module declaration §11.

An automation built on unverified knowledge automates mistakes. That is the whole
reason this folder is last.
