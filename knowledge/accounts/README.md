# Account dossiers (chains first)

One file per chain / major account. **Slow facts only** (identity, structure, tags,
relationship history, decisions); every volatile number (last order, value, cadence)
lives in `evidence/` snapshots or is computed fresh via `recipes/`.

## Dossier template

```markdown
# <Chain name>
- shopify_tag(s): <tag>            [system_verified, date]
- branches known: <list, as-of date> [system_verified]
- hq / decision maker: ?           [pending Interview #2/#4]
- relationship story: ?            [user_confirmed only]
- terms & pricing: ?               [pending Interview #3]
- open questions: U-xxx refs
- latest evidence: evidence/<file>
```
